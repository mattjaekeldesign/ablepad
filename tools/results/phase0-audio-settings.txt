# --- derived latency, NOT measured ---
# One buffer at 512/44100 = 11.61 ms.
# The manual measures DAW round trip at a 32-sample buffer as 5 ms @ 44.1 kHz
# (p.39), which implies ~3.5 ms of fixed overhead once the buffer term is removed.
# Extrapolating: 2 x 11.61 + 3.5 ~= 27 ms round trip.
#
# TREAT THAT AS AN ESTIMATE. Ableton reports the real figure as "Overall Latency"
# in Preferences > Audio. That number is authoritative and should replace this one.
