# --- what is good about this ---
# The EVO 8 is plugged straight into the machine rather than through a hub. That is
# the right call for the audio interface: fewer hops, and the phantom-power budget
# (manual p.22) depends on what the HOST port can deliver, not what a hub passes on.

# --- ANSWERED 2026-08-13 ---
# The EVO is USB-C at the device, USB-A at the host. So the host port is USB-A and
# only 2 of the 4 phantom channels can run +48 V at once (EVO manual p.22).
# Two XLR cables are on hand, so this fits -- by coincidence, not by headroom.
#
# Machine: Beelink AZW MINI S, BIOS MS2V003, Intel N150.
# Controllers: Intel xHCI USB 3.20 and USB 3.10.
# Windows exposes NO Type-C connector manager, no UCSI, no USB4. Suggestive that
# there is no USB-C host port, but NOT proof -- a USB-C port wired as plain USB 3.x
# data need not present one. Confirm by looking at the back of the unit.
#
# The cable in use is not the supplied one: Audient ships C-to-C (p.40), which cannot
# reach a USB-A host. The C-to-A cable is load-bearing kit. Carry a spare.
#
# Both CONTROLLERS sit behind external hubs. The Launchpad is bus-powered and its
# manual (p.5) warns low brightness may be REQUIRED for some hosts to power it at
# all. If it ever fails to enumerate at boot, hub power is the first suspect, ahead
# of the cable.
